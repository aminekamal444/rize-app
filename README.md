# RIZE

RIZE is an AI-powered men's glow-up coach built for the Moroccan and broader MENA market. It guides users through a structured 30-day transformation journey covering hair, style, fitness, and skin — with daily actions, weekly AI re-scoring, progress tracking, a persistent AI coach, and a wardrobe builder. The interface supports French, English, and Arabic.

## Quick start

```bash
git clone <repo-url>
cd rize
cp .env.example .env        # fill in your real secrets
pip install -r requirements.txt
python app.py
```

Open `http://localhost:5000` in your browser.
